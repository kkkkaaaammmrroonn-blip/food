# FoodExpress — Taom yetkazib berish xizmati 🍕🍔🥤

Restoran taomlarini tanlash, qidirish, savatchaga qo‘shish va buyurtma berish uchun zamonaviy veb-ilova.

---

## 🌟 Asosiy Imkoniyatlar

1. **Restoran taomlari katalogi**:
   - Har bir taom uchun yuqori sifatli rasmlar, tavsif, masalliqlar, og‘irlik/o‘lcham va kaloriya ma’lumotlari.
   - Reyting tizimi va sharhlar soni.
   - Maxsus belgilar (*Xit taom*, *Yangi*, *Super Xit*, *Achchiq 🔥*).

2. **Kategoriyalar**:
   - 🍕 **Pizza** (Pepperoni, Margarita, 4 Pishloqli, Tovuqli va Qo'ziqorinli, Go'shtli Mix, BBQ)
   - 🍔 **Burger** (Classic Cheeseburger, Double Smash, Crispy Chicken, BBQ Bacon, Big Boss, Jalapeno)
   - 🥤 **Ichimliklar** (Coca-Cola, Fanta, Sprite, Qulupnayli Mojito, Yangi siqilgan apelsin sharbati, Muzdek choy)
   - 🍽️ **Barchasi** (Barcha taomlarni bitta joyda ko'rish)

3. **Tezkor qidiruv**:
   - Taom nomi yoki tarkibidagi masalliqlar bo'yicha real vaqtda qidirish.
   - Qidiruv natijalarini tozalash va toifalar bo'yicha filtrlar.

4. **Interaktiv Savatcha va Narxni hisoblash**:
   - Kartochkaning o‘zidan yoki savatcha ichidan taomlar sonini o‘zgartirish (`+` / `−`).
   - Umumiy taomlar narxi (subtotal).
   - 100 000 so‘mdan yuqori xaridlarga **bepul yetkazib berish** va maqsad ko‘rsatkichi (progress bar).
   - Promokod tizimi (masalan: `FOOD2026` 15% chegirma beradi).
   - Jami to‘lov summasini bir zumda dinamik hisoblash.
   - `localStorage` orqali savatcha ma'lumotlarini saqlab qolish.

5. **Buyurtmani rasmiylashtirish (Checkout)**:
   - Buyurtmachi ismi, telefon raqami, yetkazish manzili va kuryer uchun izoh kiritish.
   - To‘lov turlari: *Payme*, *Click*, *Karta* yoki *Naqd pul*.
   - Muvaffaqiyatli buyurtma xabari, buyurtma ID raqami va yetkazib berish bosqichlari kuzatuvi.

---

## 🚀 Loyihani ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dasturni ishlab chiqish (dev) rejimida ishga tushirish
npm run dev

# Ishlab chiqarish (build) uchun yig'ish
npm run build

# Yig'ilgan loyihani ko'rish (preview)
npm run preview
```
